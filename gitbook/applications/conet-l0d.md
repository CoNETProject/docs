# `conet-l0d` documentation moved

`conet-l0d` is the Linux server/client runtime for `web3://`; it is not a
separate application or protocol. This compatibility page is intentionally
not listed as another GitBook application.

Operator how-to lives on the Developers page (including SI discovery from
GuardianNodesInfoV6, `si_pool_from_contract`, and duplex-primary CLI).
